# Memory Index

Local portable memory for AllForOne. Never published.

## Rules

- Save durable preferences, corrections, project decisions, and references only.
- Never save credentials, customer data, employer internals, or private repository names.
- Verify memory against the live workspace before acting on it.
- Use `allforone_memory_add` when available; it rejects common secret patterns.

## Topics

- `topics/user.md` — role, goals, preferences, responsibilities.
- `topics/feedback.md` — corrections and confirmed non-obvious approaches.
- `topics/project.md` — decisions, owners, deadlines, constraints.
