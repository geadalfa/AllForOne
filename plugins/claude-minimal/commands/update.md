---
description: Update the AllForOne Claude plugin from its marketplace
---

1. Run `claude plugin marketplace update allforone`.
2. Run `claude plugin update <edition>@allforone`, where `<edition>` is `allforone-minimal` or `allforone-full`.
3. Report the version before and after. If nothing changed, say so.
4. Tell the user to start a new session or run `/reload-plugins` so the new skills load.
