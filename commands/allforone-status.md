---
description: Show AllForOne version, plugin path, skill count, profiles, upstreams, and update state
---

Run:

```bash
npx --yes github:geadalfa/AllForOne status
```

If the `allforone` binary is not on PATH, run:

```bash
npx github:geadalfa/AllForOne status
```

Report the version, install mode, plugin path, installed skill count, memory path, auto-update flags, and the last update report. Do not invent values.
