# Artwork

Both files are edited fan media, not software assets.

- `banner.png` — 1920×1080 hero banner. Edited from “Armored All Might vs. All For One” on the My Hero Academia Fandom wiki. Added a dark gradient, a red/cyan split accent line, the ALL FOR ONE wordmark, and the tagline.
- `logo.png` — 1024×1024 square crop of the same source, centered on the split face.

Source: <https://static.wikia.nocookie.net/bokunoheroacademia/images/0/0e/Armored_All_Might_Vs._All_For_One.png>
