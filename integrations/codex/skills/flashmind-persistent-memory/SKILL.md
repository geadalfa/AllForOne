# Flashmind and Engram memory workflow

Use the active project's configured Engram or Flashmind integration when available and authorized. Verify the actual MCP tool schemas or run `engram --help` before using that CLI. For a fresh Codex installation use the [AllForOne memory helper](../allforone-memory/SKILL.md).

## Start or resume a task

Request just the matching project decisions, preferences, or known failures from memory. Use the current checkout, test results, and primary sources to verify details. Treat a search miss as an unknown.

## Record a durable outcome

When asked to save a lesson or decision, use the same memory store with these fields:

- **What** describes the observation or decision.
- **Why** captures the verified cause or trade-off.
- **Where** names the relevant path or artifact.
- **Lesson** explains what to reuse next time.

Keep the entry short. Exclude tokens, personal identifiers, and raw logs. Maintain one note for a given decision and update it when the evidence changes.

Separate verified facts, assumptions, and unknowns in user-facing reports. Memory can direct an investigation. Current evidence establishes the result.
